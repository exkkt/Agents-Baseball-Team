# 球団の箱庭 — 作業メモ

AIエージェントが幹部・監督・コーチ・選手を担当する「野球球団の箱庭」。2026-10-26 にローカルLLM（Ollama）の判断と、練習・疲労・睡眠・成長の計算を接続した（旧デモ台本は `?mode=demo`）。
参考モック: `~/.codex/visualizations/2026/10/24/01a16ee4-…/tiny-ballclub.html`（単一HTML・人物は全員同じ立ち絵・場面3枚の切り替え）
実装: `dist/ballclub.html` ＋ `dist/ballclub/`（`npm run dev` → http://127.0.0.1:4173/ballclub.html）

## Pixel Agents の観察（2026-10-25、公開リポジトリ main を読んで確認）

- 16px タイル。人物は 16×32 枠に約 16×24 の2頭身。頭が全高の4割強、暗い輪郭線と2〜3段の陰影。
- 1人物 7フレーム × 3方向（下・上・右、左は右の反転）。歩行3枚を 0,1,2,1 で循環、タイピング2枚、読書2枚。
- 着席は「専用の座りフレーム（脚が短い）＋描画位置を 6px 下げる」。椅子に深く腰掛けて見える。
- 前後関係は足元 y で並べ替え。机は前面の y、背もたれが手前に来る椅子は人物より手前に描く。
- 机の手前側に座る人は顔が見え、机の天板が腰から下を隠す。奥側に座る人は背中とモニター画面が見える。
- 壁は「暗い天端＋2タイル分の壁面」。本棚・時計・絵は壁面に掛かり、床材は部屋ごとに変える。
- 歩行は 48px/秒・1フレーム 0.15秒、タイル上の経路探索。待機は静止、作業中だけ手が動く。
- 吹き出しは 11×13px の小さなドット絵（「…」「✓」）。選択中は白い 1px 輪郭。

## 方針

1. **行動は「姿勢 × 道具 × 家具 × 時間」で見せる。** 着席・PC・素振り/打撃・投球を最優先で作り込み、ほかの行動は同じ骨格（関節位置）で派生させる。
2. **粒度を統一する。** 世界は 16px タイルの原寸キャンバス（736×480）に描き、表示は整数倍で拡大。日本語の文字だけ画面解像度で重ねる。
3. **データと描画を分ける。** `world`（地図・家具・利用地点）/ `sim`（人物の状態・意図・移動・練習の段取り・出来事）/ `director`（デモ台本。後でAIに差し替える層）/ `render`・`sprites`・`furniture`（見た目）/ `app`（UI）。
4. **野球らしさは横向きで。** 打撃・投球・キャッチボール・ノックは側面の向きに配置し、ボールを実体として飛ばす。
5. **既存構成に合わせる。** 依存パッケージなし・ESモジュール・`dist/` を `server.mjs` で配信・`node --test`。
